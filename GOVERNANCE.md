# Governance

## Scope

`sf-omp` is an unofficial, personally maintained fork of
[Salesforce SF Pi](https://github.com/salesforce/sf-pi) that runs a selected
subset of its extensions on a repository-local OMP runtime. It is not a
Salesforce project.

## Maintainer

| Maintainer    | GitHub                                             | Areas     |
| ------------- | -------------------------------------------------- | --------- |
| alexander-vyh | [@alexander-vyh](https://github.com/alexander-vyh) | All areas |

The maintainer makes the final call on merges, releases, and security
advisories. Code ownership is listed in [`.github/CODEOWNERS`](./.github/CODEOWNERS).

For suspected vulnerabilities, follow [`SECURITY.md`](./SECURITY.md). Do not
open a public issue with sensitive report details.

## Upstream

Upstream SF Pi has its own governance, maintainers, and Salesforce CLA. Changes
that belong upstream should be proposed in `salesforce/sf-pi`; this fork
periodically rebases onto upstream `main`.
